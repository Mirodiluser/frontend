## Содержание и проверки корректности
- 11 глав: вступление → обзор платформы → регистрация и вход → Kirill ↔ Latin (включая AI bilan aniqlash) → DOCX PRO (документ до/после) → Imlo Tahrirchi (жёлтое выделение maktbga, kitobb, muhokma) → Fayl Konverter → баланс → оплата (PENDING → REVIEW → PAID) → приватность → финал.
- Интерфейс — реконструкция по актуальному коду frontend (живой сайт недоступен из среды рендера); в кадре помечено «Namoyish · demo maʼlumotlar» / «Interfeys rekonstruksiyasi».
- Нет входа через Google, нет цены за страницу (сумма замаскирована), реквизиты и QR — демонстрационные, ускоренное ожидание помечено «Kutish vaqti tezlashtirilgan».
- Все кириллические/латинские строки сгенерированы реальным `app/lib/uzTranslit.ts` (обратная проверка без расхождений).
- Версия с озвучкой: `out/final/TAHRIR_AI_Premium_FullHD30_UZ_voice.mp4` (133 МБ) — голос `uz-UZ-SardorNeural` (Microsoft Edge neural TTS через MCP-сервер transcript-tts), это синтез, а не запись диктора.
  - 13 фрагментов, каждый укладывается в окно своей сцены (темп −4 %, в двух местах +5…+7 %).
  - Голос ≈ −18 dBFS RMS, музыка под голосом приглушается ≈ на 7 дБ (−32.8 против −25.9 dB), не исчезает.
  - Итог: −15.9 LUFS, пик −1.8 dBFS, декодирование без ошибок; встроены узбекские субтитры (mov_text), синхронные с речью.
- Текст диктора и субтитры: `voiceover/script_uz.md`, `voiceover/script_uz.srt`, текст для синтеза: `voiceover/tts_segments.json`.
